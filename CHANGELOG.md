# Changelog

Todas as mudanças relevantes do Bench Pro Core são documentadas neste arquivo.

## 0.1.0

- Criada fundação arquitetural do Bench Pro Core.
- Adicionada documentação do ecossistema, Integration Contract v1, lifecycle, versionamento e ADRs.
- Adicionado discovery de módulos via entry points `benchpro.modules`.
- Adicionado loader, registry e validação de contrato.
- Adicionada GUI shell em PySide6 com navegação, estado vazio, container de módulos e diálogo Sobre.
- Adicionados testes de contrato, discovery, lifecycle, isolamento de falhas, UI shell e integração multimódulo.
- Validada integração real com DNS Bench Pro e SMTP Bench Pro.
