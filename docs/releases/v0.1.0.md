# Bench Pro Core v0.1.0

## Resumo

A versão **0.1.0** estabelece a fundação do Bench Pro Core como aplicação agregadora do ecossistema Bench Pro.

O objetivo desta versão é provar a arquitetura federada:

```text
Bench Pro Core
      ↓
Micro aplicações independentes
```

## Principais recursos

- Discovery de módulos via entry points.
- Validação do Integration API v1.
- Carregamento e inicialização de módulos.
- Container genérico para widgets PySide6 fornecidos pelas micros.
- Navegação dinâmica de módulos.
- Isolamento de falhas.
- Shutdown coordenado.
- Documentação arquitetural e ADRs.

## Integrações validadas

- DNS Bench Pro 1.0.0.
- SMTP Bench Pro 0.2.5.
